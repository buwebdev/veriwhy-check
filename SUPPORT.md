# Support

Author and maintainer: Richard Krasso

## Students

Start with these commands:

```text
veriwhy-check doctor
veriwhy-check help
veriwhy-check list WEB-425
```

If a check does not finish, copy the complete error message and the output of
`veriwhy-check doctor`. Do not share your assignment source, passwords, access
tokens, or private repository links in a public issue.

Questions about grades, deadlines, or assignment interpretation belong in the
course's normal instructor-support channel. VeriWhy Check reports practice
results; it does not assign the official grade.

## Bug Reports

Use the repository's bug-report form. Include:

- the VeriWhy Check version;
- operating system;
- course and assignment identifier;
- the command entered;
- the sanitized error message; and
- whether `veriwhy-check doctor` reports an action needed.

Security or privacy concerns must follow [SECURITY.md](docs/SECURITY.md).
