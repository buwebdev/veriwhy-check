# Privacy and Security

## Your Code Stays Local

VeriWhy Check does not upload source code or reports. It contains no telemetry,
advertising, analytics, or cloud artificial intelligence.

## Temporary Project Copy

Checks use a temporary copy so generated dependencies and test files do not
rewrite the original assignment. The copy is removed after the check, even
when a requirement fails.

## Separate Testing Browser

Browser checks use Playwright's managed headless Chromium shell. It is not a
normal application, does not add a Chrome for Testing entry to macOS
Notifications, and is separate from your installed Chrome, Edge, Firefox, or
Safari. It does not use their profiles, cookies, extensions, history,
bookmarks, or saved passwords.

External page requests are blocked during a browser assessment. The assignment
page is served only through a temporary address on your own computer.

## Network Activity

Network access is used to install or update VeriWhy Check and may be used to
install dependencies declared by an npm project. Normal checks do not contact
a VeriWhy Check server.

## Public Requirements

Assessment profiles and functional checks are intentionally visible. They
describe the published assignment behavior and contain no instructor
credentials, reference solutions, or official grade points.
