# Welcome to VeriWhy Check

VeriWhy Check is a practice coach for coding assignments. It checks the
published functional requirements before you submit your work and creates a
local report that explains what passed and what needs attention.

## Begin Here

1. Open a terminal in or near your assignment folder.
2. Find your assignment command with `veriwhy-check list WEB-425`.
3. Run the command shown, such as `veriwhy-check check WEB-425/lab-1.1`.
4. Open the generated report.
5. Correct anything marked **Needs attention**, then check again.

If terminal commands are new to you, open the
[Beginner CLI Guide](cli-basics.html). It illustrates how to find your current
folder, display its contents, move between folders, and recover from common
errors.

If you are unsure where your work should be saved, open the
[Project Folder Guide](project-folders.html). It uses simple pictures to show
which folders and files belong together for each course.

> VeriWhy Check provides practice feedback. It does not assign your official
> course grade.

## What It Checks

Depending on the course, VeriWhy Check can inspect required files, application
behavior, browser output, Node.js output, Angular builds, and published tests.
It focuses on whether the solution works and meets the assignment requirements.

It does not deduct points for indentation, spacing, naming preferences,
comments, or whether your solution resembles another person's code.

## Private by Design

Checks run on your computer. VeriWhy Check does not upload your source code,
use a cloud AI service, collect analytics, or open your personal browser
profile. Browser assignments use a separate testing browser.

## Useful Commands

```text
veriwhy-check help
veriwhy-check guide
veriwhy-check doctor
veriwhy-check paths
```
