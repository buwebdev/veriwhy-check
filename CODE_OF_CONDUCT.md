# Code of Conduct

Author and maintainer: Richard Krasso

## Our Standard

VeriWhy Check is an educational project. Participants must communicate with
patience, respect different levels of technical experience, welcome questions,
and give specific, constructive feedback.

Unacceptable behavior includes harassment, discrimination, intimidation,
publishing another person's private information, sharing student submissions,
or using project spaces for unrelated promotion.

## Scope and Enforcement

This standard applies in project repositories, issue trackers, reviews, and
other spaces where someone represents the project. Report conduct concerns
privately to the repository owner through the contact method listed on the
GitHub organization profile. Do not place private or student information in a
public issue.

The maintainer may edit or remove contributions and restrict participation
when behavior is inconsistent with this standard.
